# AI Developer Portfolio Workshop

This repository is a workshop example project designed to demonstrate how modern AI coding tools can rapidly generate and improve a frontend website using a small set of starter assets.

## Included Assets

This repo contains:

- A sample resume
- A professional headshot
- Supporting project structure for building a developer portfolio website

The goal is to use these assets as the foundation for an AI-assisted frontend development workflow.

---

## Workshop Objectives

During this workshop, we'll explore how to:

- Use AI coding assistants to scaffold and build a frontend website
- Generate layouts and components from existing assets
- Improve design and UX through iterative prompting
- Use specialized tools, plugins, and workflows to enhance output quality
- Refine styling, animations, responsiveness, and visual polish
- Experiment with AI-assisted content generation and editing

Rather than building everything manually, we'll focus on directing AI systems effectively and learning how experienced developers can amplify their workflow with modern tooling.

---

## Topics We'll Explore

Some examples include:

- AI-powered code generation
- Frontend scaffolding
- Component-based UI development
- Prompt engineering for developers
- Design iteration workflows
- Context files and structured instructions
- Plugin and MCP integrations
- Styling and animation improvements
- AI-assisted debugging and refactoring

---

## Important Note

This repository is intentionally simplified for educational purposes.

The resume, headshot, and portfolio content are example materials used for demonstration inside the workshop environment.

---

## Recommended Stack

You can adapt this project to many frontend stacks, including:

- React
- Next.js
- Tailwind CSS
- Vite
- Framer Motion
- shadcn/ui

You are encouraged to experiment with different tools and workflows throughout the workshop.

---

## Goal

By the end of the workshop, participants should better understand how to:

1. Collaborate effectively with AI coding tools
2. Turn raw assets into polished frontend experiences
3. Iterate faster while maintaining developer oversight
4. Use AI as a force multiplier rather than a replacement
